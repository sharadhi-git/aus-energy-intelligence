# Australian Energy Market Data Platform

## Project Overview 

This project aims to build an end-to-end data engineering platform using real-world electricity market data from the Australian Energy Market Operator (AEMO).

The platform will process and transform large volumes of electricity market data to support analytics, reporting and machine learning applications.

The main objective is to develop practical experience in modern data engineering technologies, cloud platforms and scalable data processing.

## Technologies

1. Programming : Python, SQL, PySpark
2. Data Processing: Apache Spark, Databricks, Delta Lake
3. Data Warehouse : Snowflake, dbt
4. Cloud: AWS  S3
5. Data Visualization : Power BI
6. Development : Git, GitHub, Docker, CI/CD

## Project Objectives

- Build reliable and scalable data ingestion pipelines using AEMO datasets
- Implement bronze, silver and gold data layers using PySpark and delta Lake
- Develop automated data transformations and quality checks
- Integrate processed data with Snowflake for analytics
- Evaluate pipeline performance and optimise processing efficiency
- Prepare curated datasets for business intelligence and machine learning
